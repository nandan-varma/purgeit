---
name: purgeit
description: Find and safely delete regenerable dev build artifacts (node_modules, target, dist, Pods, .next, …) to free disk space. Use when asked to clean up, free space, or purge build output across projects.
---

Run `npx purgeit skill` (or `purgeit skill` if installed) and follow the guide it prints. The guide is
versioned with the CLI, so it always matches the installed commands.
