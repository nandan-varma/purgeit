{`purgeit [dirs…]            browse and select in the interactive UI (default)

Flags beat the [config file](/docs/reference/configuration). Sizes use binary units (`1KB` = 1024 bytes); durations accept `ms`, `s`, `m`, `h`, `d`, `w`, `y` (and `0`). Output formats are described in [Output formats](/docs/reference/output-formats).

## clean

`--min-age` defaults to `7d` for `clean` and doubles as a guard: anything with a change inside that window is skipped at deletion time, whatever the scan said. See [Clean safely](/docs/guides/clean-safely).

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success |
| `1` | some paths were skipped or failed, or you declined the confirmation |
| `2` | bad arguments, config or plan |
| `70` | internal error |
| `130` | interrupted |

## Environment

purgeit honours `NO_COLOR`. History lives in `~/Library/Logs/purgeit/history.jsonl` on macOS, `$XDG_STATE_HOME/purgeit/` (default `~/.local/state/purgeit/`) on Linux and `%LOCALAPPDATA%\purgeit\Log\` on Windows.
