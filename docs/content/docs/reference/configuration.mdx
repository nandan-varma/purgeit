purgeit reads, from the working directory (or `--config <file>`), the first of `purgeit.config.ts`, `.mts`, `.js`, `.mjs`, `.cjs`, `.json`, or the `purgeit` key of `package.json`. TypeScript configs load directly. Unknown keys and bad values are rejected with the file and the problem named. For recipes see [Custom rules](/docs/guides/custom-rules).

## Rule shapes

```ts
gated:   [{ name: 'out', when: { file: 'project.toml' }, description?: string }]
markers: [{ name: 'MYTOOL.TAG', file: '.mytool-cache', signature: 'mytool-cache-v1' }]
```

`when` is one condition, or a list of which any one suffices:

| Condition | Holds when… |
| --- | --- |
| `{ file: 'package.json' }` | that file sits beside the directory |
| `{ glob: '*.xcodeproj' }` | any sibling matches |
| `{ grep: { file, pattern } }` | that sibling's contents match the regex (unreadable ⇒ no proof) |

Names are plain file names, never paths. `file` and `glob` are answered from the directory listing the scanner already has, so they cost nothing.

## Schema

The JSON Schema ships with the package as `purgeit/schema.json` and is used for editor completion:

```json
{ "$schema": "./node_modules/purgeit/schema.json" }
```
