<CardGrid stagger>
  <Card title="Safe by construction" icon="approve-check">
    Nothing is preselected. Every path is **re-verified at the moment of deletion** — rules, git, deploy keys, recent activity, symlink tricks. [Read the safety model](/concepts/safety-model/).
  </Card>
  <Card title="Fast" icon="rocket">
    One traversal measures size, file count and last activity — as fast as `du`. [How it works](/concepts/how-it-works/).
  </Card>
  <Card title="Honest numbers" icon="information">
    Sizes are space that deleting would actually free; hardlinked files (pnpm's store) aren't double counted.
  </Card>
  <Card title="Interactive UI" icon="laptop">
    A full-screen terminal UI that fills in as results arrive: sort, filter, select, confirm. [Tour](/guides/interactive-ui/).
  </Card>
  <Card title="Scriptable" icon="terminal">
    JSON and NDJSON output, reviewable plans, dry runs and stable exit codes. [Automate it](/guides/automation/).
  </Card>
  <Card title="Made for AI agents" icon="seti:mcp">

  </Card>
  <Card title="65 rules, extensible" icon="setting">

  </Card>
  <Card title="A library, too" icon="puzzle">
