purgeit needs **Node.js 22 or newer** on macOS, Linux or Windows. It is published to npm with [signed provenance](https://docs.npmjs.com/generating-provenance-statements).

<Steps>

1. **Run it.** No install needed:

   <Tabs syncKey="pm">
     <TabItem label="npx">`npx purgeit ~/dev`</TabItem>
     <TabItem label="bunx">`bunx purgeit ~/dev`</TabItem>
     <TabItem label="pnpm">`pnpm dlx purgeit ~/dev`</TabItem>
   </Tabs>

   With no directory it scans the current one. Add `--discover` to also scan the places this machine keeps projects (`~/dev`, `~/Projects`, `~/Code`, AI agent worktrees, and any home folder that holds projects).

2. **Look around.** The [interactive UI](/guides/interactive-ui/) fills in as artifacts are measured. Press `space` on what you want gone, `enter` to review, `y` to delete.

3. **Or stay in the shell.** List without changing anything, then clean with a preview first:

   ```bash
   purgeit scan ~/dev --min-size 100MB
   purgeit clean ~/dev --min-size 100MB --dry-run   # runs every check, deletes nothing
   purgeit clean ~/dev --min-size 100MB             # asks first
   ```

</Steps>

## What you are looking at

| Column | Meaning |
| --- | --- |
| **SIZE** | Disk space deleting it would free |
| **AGE** | Time since anything inside last changed |
| **RULE** | Which rule claimed the directory (`purgeit rules` lists them all) |
| **PATH** | The directory |

<Aside type="tip" title="Safe by default">
`clean` leaves anything modified in the last **7 days** alone, never deletes without confirmation (or `--yes`), and refuses anything it cannot verify. See [Clean safely](/guides/clean-safely/) and the [safety model](/concepts/safety-model/).
</Aside>
